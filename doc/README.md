# doc 目录导航

本目录有两套来源不同的文档。**先读 `09_设计文档与实现现状对照.md`**，它说明两者的分工、冲突点，以及冲突时以谁为准。

## 本仓库自有

| 文件 | 内容 | 权威性 |
| --- | --- | --- |
| `../CLAUDE.md` | 工程约定：目录结构、分层、API 约定、FreeSql 实体写法、安全 | 描述已存在的代码，最高 |
| `开发计划1.0.md` | 功能模块清单、数据模型规划、外部系统对接、分期开发计划 | 已确认到 v1.3 |

## 从 smilecheck-app2 迁入

来自六次会议录音与商业计划书的整理，写作时不知道本仓库存在，技术实现部分需按对照文档修正。

| 文件 | 内容 | 直接可用 |
| --- | --- | --- |
| `00_历次会议大纲.md` | 按时间线归纳 7 月计划书与 6 次会议，含角色表、跨会议已决与未决事项 | 是 |
| `01_产品大纲.md` | 产品定位、核心业务规则、信息架构、功能模块拆分、用户旅程 | 是 |
| `02_产品实现Roadmap_三步走.md` | 保持器切入 → 保持器加微调 → 正畸平台的业务阶段 | 是，但不用于排开发 |
| `03_小程序平台架构设计.md` | 架构总纲 | 部分，技术选型以 CLAUDE.md 为准 |
| `04_小程序开发Roadmap.md` | **V2.0**，已按本仓库技术栈重写：阶段 0 到 5 加阶段 2B 保持器订单，含前置修复清单、外部依赖、日历约束 | 是，与 `开发计划1.0.md` 同一套阶段编号 |
| `05_M0详细设计.md` | 16 条架构决策、API 与插件契约、小程序分包与页面清单 | 部分，已在原文逐条标注被证实或推翻 |
| `06_阿里云基础设施部署手册.md` | ECS 初始化、Docker Compose、nginx、备份监控、上线检查清单 | 是，OSS 与 CDN 两节留到切云存储时用 |

| `08_数据库关系图与模块关系图.md` | 16 张 Mermaid 图 | 第 9 到 14 节的模块图可用；第 1 到 8 节的 ER 图对应 `07` 的表结构 |
| `09_设计文档与实现现状对照.md` | 两套文档的对照与决策清单 | 是，入口文档 |
| `10_现有实现评审.md` | 对 `api/`、`docker/`、`tools/` 现有代码的逐文件评审：10 项阻塞缺陷、安全、数据层、运维、修复工时与验证清单 | 是，阶段 0 的工作来源 |
