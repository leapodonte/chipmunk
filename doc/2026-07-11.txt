2026-07-11 | 文档摘要：牙套e家 AI口腔健康平台商业规划计划书（送审版 V1.0，2026年7月，内部讨论稿）

说明：本摘要只提炼技术要点与产品要点。原文中的股权结构、工商登记、代持安排、员工激励池、融资稀释、家庭成员确认、开发垫资等内容已全部去除。

一、项目定位
- 品牌暂名"牙套e家"，定位为"正畸后保持与牙套管理平台"，以微信小程序为入口。
- 一句话定位：牙套e家 = 正畸后保持器复购 + 口扫数据建档 + 反弹监控 + 轻微微调服务平台。
- 第一阶段对外不以"AI诊断"为定位，走"口腔健康自测 + 正畸后保持管理 + 保持器复购 + 轻微微调适合度评估"的低风险、低成本切入路径。
- 三条业务线：AI口腔健康小程序（低成本获客与用户教育）→ 透明保持器平台（第一现金流与复购）→ 轻微反弹微调平台（更高客单价、第二增长曲线）。
- 三条业务线共用：用户账户、口扫数据、后台系统、医生审核流程、代工厂接口、运营体系。

二、战略边界（阶段性不做）
- 不以"AI诊断"对外宣传，第一阶段只做健康自测与风险提示。
- 不直接开展互联网诊疗（涉及互联网医院、执业医生、电子病历、留痕和医疗机构主体要求）。
- 不自建医疗器械生产资质，透明保持器与具备二类医疗器械注册和生产资质的代工厂合作。
- 不一开始做复杂 App，先做小程序（成本低、传播快、验证周期短）。
- 不使用杨老师个人 IP：产品内和宣传中不得出现"杨老师推荐 / 杨老师团队 / 杨老师正畸平台"等表述，对外品牌只围绕"牙套e家"。医生、诊所、互联网医院合作一律通过独立商业协议。

三、业务线一：AI口腔健康小程序（用户入口）
核心内容：游戏化牙齿自测、正畸后保持科普、照片/问卷自测报告、保持器复购提醒、口扫预约、留资。
MVP 模块：
- 首页：品牌介绍、核心入口、热门自测、保持器复购入口。目标是让用户快速理解平台价值。
- 牙齿自测：综合自测、嘴凸/侧脸自测、拥挤自测、儿童早矫自测（问卷形式，低成本收集用户需求和风险标签）。
- 照片上传：微笑正面照、咬合照、侧脸照，可选上传；用于提升报告体验并积累数据。
- 自测报告：评分、类型、风险提示、科普推荐、下一步建议；目标是增强停留和分享，形成留资转化。
- 保持器管理：复购提醒、佩戴提醒、口扫建档、订单入口；把一次性访问转化为长期服务。
- 后台系统：用户、报告、线索、订单、内容、渠道数据管理；支撑运营和数据沉淀。

四、业务线二：透明保持器平台（第一现金流）
- 用户完成口扫建档后，基于口扫模型复购透明保持器。平台负责获客、系统、订单、医生/机构协作、复购提醒；生产交由合规代工厂。
- 服务与建议价格区间：
  · 口扫建档（合作诊所或口扫点完成上下颌口扫，建立最终牙列模型档案）：99–299元
  · 单副保持器（单颌）：199–399元
  · 上下颌一套：399–699元
  · 年度保持计划（复购 + 佩戴提醒 + 定期复测提醒 + 会员折扣）：699–1299元
  · 诊所白牌服务（保持器订单系统 + 代工厂交付能力）：按订单分成
- 业务流程（6 步）：
  1. 用户通过小程序完成自测或保持器需求登记
  2. 用户预约合作诊所或口扫点完成口扫建档
  3. 医生或合作机构确认是否适合制作保持器
  4. 平台将口扫数据和订单信息发送给合规代工厂
  5. 代工厂生产透明保持器并发货
  6. 平台保存数据，提醒复购、复查和反弹监控
- 单副成本结构示例（售价 299 元）：工厂成本约 100 元（需按实际代工报价校准）、物流包装约 20 元、医生/诊所分成约 50 元、平台毛利约 129 元（约 43%，未扣获客、客服、管理费用）。

五、业务线三：轻微反弹微调平台（第二增长曲线）
- 适用场景：正畸后轻微反弹、前牙小范围不齐、轻微牙缝复发、极轻度美观性微调等低难度场景。
- 必须走"AI/规则初筛 + 口扫数据 + 医生审核 + 合规生产 + 佩戴监控"路径，AI 不得自动输出治疗方案。
- 套餐设计：
  · Mini：单颗或少数牙轻微调整、轻微牙缝复发，3–5 副，999–1999 元
  · Standard：前牙轻微反弹或轻度排列调整，6–10 副，1999–3999 元
  · Pro：复杂度略高但仍属轻症范围，10–15 副，3999–5999 元
- Standard 成本结构示例（售价 2999 元）：牙套生产约 1000 元（10 副左右）、医生审核/服务约 500 元、口扫/诊所服务约 300 元、物流/客服/售后约 200 元、平台毛利约 999 元（约 33%）。

六、核心数据路径（技术要点）
- 核心资产不是单次订单，而是用户的正畸后口扫模型、保持器复购记录、佩戴提醒数据、反弹监控数据和医生审核记录。
- 数据流：
  · 用户进入：小程序自测、问卷、照片、渠道来源 → 生成标签和报告 → 获客、分层、转化
  · 口扫建档：诊所或口扫点上传 STL/PLY 模型 → 保存最终牙列数据 → 作为后续复购和反弹对比的基线
  · 保持器订单：口扫模型、生产参数、订单状态 → 对接代工厂生产 → 现金流和复购
  · 反弹监控：周期照片、复扫模型、用户反馈 → 对比变化、提示复查 → 筛选微调病例
  · 微调服务：口扫、医生审核、分步方案、佩戴记录 → 形成标准化轻症服务流程 → 高客单价业务
- 技术分工（仅取职责，不含激励信息）：
  · Jerry：小程序前后台核心开发
  · Xiaocong：UX/UI、问卷体验、报告页、转化设计
  · Sam：后端、数据库、接口、部署、算法接入
  · 待引入算法工程师：图像识别、口扫处理、牙齿分割、微调算法
  · 待引入运营/增长负责人：内容增长、渠道转化、用户运营
  · 医生顾问/专家：医疗专业把关、审核流程、病例适应症边界
- 日常产品开发、技术架构、算法路线、后台系统由 Leo 主导；保持器供应链、诊所合作、医疗资源协调由双方共同讨论。

七、收入来源与启动优先级（产品侧）
- 高：保持器销售（单副、上下颌套装、年度保持计划）；口扫建档费（与诊所或口扫点合作收取）。
- 中高：轻微微调套餐（3–15 副透明微调牙套，医生审核后执行）。
- 中：医生/机构审核服务；诊所 SaaS 工具（口扫数据管理、订单管理、患者召回）；B 端白牌保持器和微调牙套订单系统。
- 中低：护理用品商城（保持器清洁片、牙套盒、牙刷、冲牙器等）。

八、产品实施路线图
- 阶段0（0–1 个月）：确认产品范围，产出 MVP PRD 和品牌检索。
- 阶段1（1–3 个月）AI 小程序 MVP：首页、自测、报告、留资、后台、内容管理。
- 阶段2（3–6 个月）保持器复购 MVP：诊所合作、代工厂接口、订单系统、复购提醒；验证口扫建档和保持器订单。
- 阶段3（6–12 个月）正畸末期确认服务：口扫建档套餐、医生/机构确认、年度保持计划；建立最终口扫模型留存和长期复购链路。
- 阶段4（12–24 个月，数据验证后）轻微反弹微调试点：轻症筛选、医生审核、微调方案、佩戴监控；小规模验证效果和合规闭环。
- 阶段5：规模化，完善合规和渠道，建设全国口扫/诊所网络。

九、合规边界与宣传用语（直接影响产品文案）
- 原则：非诊断、非诊疗、非医生个人背书。
- 可以使用：牙齿健康自测、正畸后保持管理、保持器复购、口扫建档、佩戴提醒、反弹监控、轻微微调适合度评估、合作机构服务。
- 禁止使用：AI诊断、AI确诊、线上诊断、在线治疗、医生确诊、AI自动治疗方案、在线开方案、医生在线治疗、平台直接诊疗、无需面诊即可治疗、保证不反弹、保证排齐、保证变美、完全替代隐形正畸、无需医生、杨老师推荐/杨老师团队/杨老师亲自把关/杨老师粉丝专享。
- 需准备的用户侧文件：用户协议、隐私政策、照片/口扫数据授权书、自测免责声明、医疗服务边界说明。
- 知识产权：软件著作权、源码、算法模型的归属需书面明确；商标申请及品牌管理需有协议。
